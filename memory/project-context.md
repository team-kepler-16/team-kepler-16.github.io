# Project Context

- **Goal:** Develop a solution for the NASA Space Apps Challenge 2026 challenge [Abandoned but Not Forgotten: Storytelling About NASA's Discarded Equipment on the Moon and Mars](https://www.spaceappschallenge.org/2026/challenges/abandoned-but-not-forgotten-storytelling-about-nasas-discarded-equipment-on-the-moon-and-mars/).
- **Current stack:** HTML5, CSS3, JavaScript, and jQuery. Additional technologies may be introduced later.
- **Responsive requirement:** The site must display and remain usable on both desktop and mobile devices.
- **Documentation language:** English.
