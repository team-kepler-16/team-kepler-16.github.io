# Project

This project develops a solution for the [NASA Space Apps Challenge 2026: Abandoned but Not Forgotten](https://www.spaceappschallenge.org/2026/challenges/abandoned-but-not-forgotten-storytelling-about-nasas-discarded-equipment-on-the-moon-and-mars/).

## Guidance
